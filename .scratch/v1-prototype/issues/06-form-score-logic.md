# 06: ตรรกะคะแนนฟอร์มการวิ่ง

**Blocked by:** 02

**Status:** done

## What to build

เพิ่มฟังก์ชันในโมดูลตัวตัดสินใจที่รับชุดตัวอย่าง cadence และ pace ตลอด Session แล้วคืน FormScore

ใช้สามสัญญาณที่มือถือวัดได้แม่นจริงเท่านั้น คือ cadence โดยรวม cadence ที่ตกลงในช่วงท้าย และ pace ที่ตกลงในช่วงท้าย ห้ามใช้ ground contact time หรือความสมมาตรซ้ายขวาเพราะมือถือในกระเป๋าวัดไม่ได้แม่นพอ

ผลลัพธ์ต้องเป็นประโยคภาษาไทยที่บอกให้ผู้ใช้ทำอะไรต่อได้ ไม่ใช่ตัวเลขลอย ๆ ตัวอย่างเช่นบอกว่า cadence ตกจากเท่าไหร่เป็นเท่าไหร่ในกิโลสุดท้าย และนั่นแปลว่าเริ่มลงส้นซึ่งเสี่ยงเจ็บหน้าแข้ง

Session ที่สั้นเกินกว่าจะสรุปอะไรได้ต้องบอกตรง ๆ ว่าข้อมูลไม่พอ ห้ามเดา

## Acceptance criteria

- [x] cadence ที่คงที่ตลอดไม่ถูกตัดสินว่าฟอร์มเสีย มีเทสต์ยืนยัน
- [x] cadence ที่ตกช่วงท้ายถูกจับได้ มีเทสต์ยืนยัน
- [x] pace ที่ตกช่วงท้ายถูกจับได้ มีเทสต์ยืนยัน
- [x] Session ที่สั้นเกินไปคืนผลว่าข้อมูลไม่พอ มีเทสต์ยืนยัน
- [x] ผลลัพธ์มีประโยคภาษาไทยที่บอกสิ่งที่ควรทำต่อเสมอ
