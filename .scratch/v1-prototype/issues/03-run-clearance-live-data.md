# 03: ใบอนุญาตวิ่งจากอากาศจริงบนหน้าแรกและหน้าอากาศ

**Blocked by:** 01, 02

**Status:** done pending device check

## What to build

ผู้ใช้เปิดแอปแล้วเห็นใบอนุญาตวิ่งวันนี้เป็นคำตัดสินสีเขียวเหลืองหรือแดงทันทีบนหน้าแรก พร้อมประโยคเดียวบอกว่าวันนี้วิ่งได้ช่วงไหน กดเข้าไปดูหน้าอากาศเต็มจะเห็นแถบเวลาทั้งวันเป็นสีเขียวเหลืองแดง อุณหภูมิที่รู้สึกได้ ความชื้น UV และค่า PM2.5 พร้อมชื่อสถานีตรวจวัดและระยะห่างจากผู้ใช้

ข้อมูลมาจาก Open-Meteo เป็นแหล่งหลักซึ่งฟรีและไม่ต้องมี API key และค่า PM2.5 มาจาก Air4Thai ซึ่งฟรีเช่นกันมีสถานีทั่วประเทศ

สถานี Air4Thai ดับได้จริง ลำดับการถอยคือใช้สถานีที่ใกล้ที่สุดที่ยังส่งข้อมูล ถ้าไม่มีเลยให้ถอยไปใช้ค่าจาก Open-Meteo ถ้ายังไม่มีอีกให้แสดงตรง ๆ ว่าไม่มีข้อมูล ห้ามเดาค่าเอง และต้องแสดงชื่อแหล่งข้อมูลกับระยะห่างเสมอ

ตัวเชื่อมทั้งสองตัวต้องแปลงผลลัพธ์เป็นชนิดข้อมูลของโดเมนที่ขอบ ไม่ส่งรูปแบบดิบของ API เข้าไปในโมดูลตัวตัดสินใจ

- [x] แสดงเหตุผลว่าอะไรเป็นตัวที่ทำให้วันนี้ไม่เขียว
- [ ] หน้าอากาศแสดงแถบเวลาทั้งวันเป็นสี
- [x] แสดงชื่อสถานีตรวจวัด PM2.5 และระยะห่างจากผู้ใช้
- [x] เมื่อสถานีใกล้ที่สุดไม่ส่งข้อมูล ระบบถอยไปสถานีถัดไปหรือ Open-Meteo และบอกผู้ใช้ว่าใช้แหล่งไหน

- [ ] แอปไม่ค้างและไม่ขาวเมื่อไม่มีอินเทอร์เน็ต

## ยืนยันกับข้อมูลจริงแล้ว

รันตัวเชื่อมทั้งหมดกับ API จริงที่พิกัด มจพ. ปราจีนบุรี เมื่อ 2026-08-27 เวลา 00:10

- แปลงเวลาถูกต้อง ชั่วโมงแรกคือ 00:00 เวลาไทย พระอาทิตย์ขึ้น 06:02 ตก 18:29
- Air4Thai เลือกสถานีที่ใกล้ที่สุดที่ยังส่งข้อมูลได้จริง คือ 105t นครนายก ห่าง 14.7 กม. PM2.5 10.2
- แถบทั้งวันออกมาเป็น yyyyyyggggrrrrgrrggyyyyy และช่วงที่ควรวิ่งคือ 06:02 ถึง 10:00

## บั๊กที่การตรวจกับข้อมูลจริงจับได้

ตอนแรกโค้ดเช็คความมืดแค่ฝั่งหลังพระอาทิตย์ตก ทำให้ชั่วโมงตีศูนย์ถึงตีห้าถูกตัดสินว่าเขียว
และช่วงที่ควรวิ่งเริ่มนับตั้งแต่เที่ยงคืน ซึ่งขัดกับปัญหาเรื่องแสงสว่างที่โปรเจกต์ตั้งไว้
แก้โดยเพิ่ม sunrise เข้าไปใน evaluateRunClearance และนับความมืดทั้งสองฝั่ง
กฎในสเปกถูกแก้ให้ตรงกันแล้ว
