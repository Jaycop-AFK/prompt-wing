# 03: ใบอนุญาตวิ่งจากอากาศจริงบนหน้าแรกและหน้าอากาศ

**Blocked by:** 01, 02

**Status:** ready-for-agent

## What to build

ผู้ใช้เปิดแอปแล้วเห็นใบอนุญาตวิ่งวันนี้เป็นคำตัดสินสีเขียวเหลืองหรือแดงทันทีบนหน้าแรก พร้อมประโยคเดียวบอกว่าวันนี้วิ่งได้ช่วงไหน กดเข้าไปดูหน้าอากาศเต็มจะเห็นแถบเวลาทั้งวันเป็นสีเขียวเหลืองแดง อุณหภูมิที่รู้สึกได้ ความชื้น UV และค่า PM2.5 พร้อมชื่อสถานีตรวจวัดและระยะห่างจากผู้ใช้

ข้อมูลมาจาก Open-Meteo เป็นแหล่งหลักซึ่งฟรีและไม่ต้องมี API key และค่า PM2.5 มาจาก Air4Thai ซึ่งฟรีเช่นกันมีสถานีทั่วประเทศ

สถานี Air4Thai ดับได้จริง ลำดับการถอยคือใช้สถานีที่ใกล้ที่สุดที่ยังส่งข้อมูล ถ้าไม่มีเลยให้ถอยไปใช้ค่าจาก Open-Meteo ถ้ายังไม่มีอีกให้แสดงตรง ๆ ว่าไม่มีข้อมูล ห้ามเดาค่าเอง และต้องแสดงชื่อแหล่งข้อมูลกับระยะห่างเสมอ

ตัวเชื่อมทั้งสองตัวต้องแปลงผลลัพธ์เป็นชนิดข้อมูลของโดเมนที่ขอบ ไม่ส่งรูปแบบดิบของ API เข้าไปในโมดูลตัวตัดสินใจ

## Acceptance criteria

- [ ] หน้าแรกแสดงคำตัดสินจากอากาศจริงของตำแหน่งปัจจุบัน
- [ ] แสดงประโยค ClearWindow บอกช่วงเวลาที่ควรวิ่งวันนี้
- [ ] แสดงเหตุผลว่าอะไรเป็นตัวที่ทำให้วันนี้ไม่เขียว
- [ ] หน้าอากาศแสดงแถบเวลาทั้งวันเป็นสี
- [ ] แสดงชื่อสถานีตรวจวัด PM2.5 และระยะห่างจากผู้ใช้
- [ ] เมื่อสถานีใกล้ที่สุดไม่ส่งข้อมูล ระบบถอยไปสถานีถัดไปหรือ Open-Meteo และบอกผู้ใช้ว่าใช้แหล่งไหน
- [ ] เมื่อไม่มีข้อมูล PM2.5 เลย แสดงว่าไม่มีข้อมูล ไม่ใช่แสดงว่าอากาศดี
- [ ] แอปไม่ค้างและไม่ขาวเมื่อไม่มีอินเทอร์เน็ต
