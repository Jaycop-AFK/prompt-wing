# 02: ตรรกะใบอนุญาตวิ่งและช่วงเวลาที่ควรวิ่ง

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## What to build

สร้างโมดูลตัวตัดสินใจซึ่งเป็น seam เดียวของโปรเจกต์นี้ พร้อมติดตั้ง vitest เป็นครั้งแรก แล้วเขียนฟังก์ชันแรกคือการประเมิน RunClearance

ฟังก์ชันรับค่าอากาศและอากาศเสียรายชั่วโมงยี่สิบสี่ชั่วโมง เวลาพระอาทิตย์ตก และเวลาปัจจุบัน แล้วคืนคำตัดสินสีเขียวเหลืองหรือแดง พร้อมเหตุผลว่าตัวไหนเป็นคนตัดสิน และคืน ClearWindow ซึ่งคือช่วงชั่วโมงเขียวติดต่อกันที่ยาวที่สุดของวันที่ยังมาไม่ถึง

กฎคือตัวที่แย่ที่สุดเป็นคนตัดสิน ไม่เอามาเฉลี่ยกัน แดงเมื่ออุณหภูมิที่รู้สึกได้ตั้งแต่ 41 องศาขึ้นไป หรือ PM2.5 ตั้งแต่ 37.5 ไมโครกรัมต่อลูกบาศก์เมตรขึ้นไป หรือมีพายุฝนฟ้าคะนอง เหลืองเมื่ออุณหภูมิที่รู้สึกได้อยู่ระหว่าง 35 ถึง 41 หรือ PM2.5 อยู่ระหว่าง 25 ถึง 37.5 หรือ UV ตั้งแต่ 8 ขึ้นไป เขียวเมื่อต่ำกว่าเกณฑ์เหลืองทุกตัวและยังไม่ถึงเวลาพระอาทิตย์ตก

โมดูลนี้ห้าม import อะไรจาก React Native เลย และห้ามเรียกนาฬิกาข้างใน เวลาปัจจุบันต้องส่งเข้าไปเป็นพารามิเตอร์เสมอ ไม่งั้นเทสต์เรื่องช่วงเวลาจะเขียนไม่ได้

## Acceptance criteria

- [ ] รันเทสต์ด้วยคำสั่งเดียวแล้วผ่านทั้งหมด
- [ ] ทุกเกณฑ์ที่ทำให้เป็นแดงมีเทสต์แยกกันทีละตัว
- [ ] ทุกเกณฑ์ที่ทำให้เป็นเหลืองมีเทสต์แยกกันทีละตัว
- [ ] มีเทสต์กรณีค่าอยู่ตรงเส้นแบ่งพอดี
- [ ] มีเทสต์กรณีตัวหนึ่งดีมากแต่อีกตัวแย่ ผลต้องออกมาตามตัวที่แย่
- [ ] มีเทสต์กรณีไม่มีค่า PM2.5 เลย
- [ ] ClearWindow มีเทสต์ครอบคลุมวันที่ไม่มีชั่วโมงเขียว วันที่มีสองช่วงต้องเลือกช่วงยาวกว่า ช่วงที่ผ่านไปแล้วต้องไม่ถูกเลือก และช่วงที่ถูกตัดด้วยพระอาทิตย์ตก
- [ ] โมดูลไม่มี import จาก react-native หรือ expo ใด ๆ
