# 10: ตั้งเป้าหมายรอบนี้และสรุปก่อนเริ่มวิ่ง

**Blocked by:** 03, 04

**Status:** done pending device check

## What to build

ผู้ใช้กดแท็บวิ่งแล้วตั้ง SessionTarget ได้ว่าจะเอาระยะทาง เวลา หรือแคลอรี เลือกจากค่าที่ตั้งไว้ให้หรือกรอกเองก็ได้ จากนั้นเห็นหน้าสรุปก่อนเริ่มวิ่งที่บอกเวลาที่คาดว่าจะใช้ แคลอรีที่คาดว่าจะเผาผลาญ และ pace ที่แนะนำ

เมื่อใบอนุญาตวิ่งวันนี้เป็นสีเหลือง ระบบต้องลด SessionTarget ให้อัตโนมัติพร้อมบอกเหตุผลเป็นข้อความที่ผู้ใช้อ่านเข้าใจ และผู้ใช้ต้องปรับกลับขึ้นเองได้ถ้ายืนยันจะทำ ระบบแนะนำ ไม่ใช่บังคับ

## Acceptance criteria

- [x] ตั้ง SessionTarget ได้ทั้งสามแบบ ทั้งค่าที่ตั้งไว้ให้และกรอกเอง
- [x] หน้าสรุปก่อนวิ่งแสดงเวลาที่คาด แคลอรีที่คาด และ pace ที่แนะนำ
- [x] วันที่ใบอนุญาตเป็นสีเหลือง ระบบลดเป้าหมายให้พร้อมบอกเหตุผล
- [x] ผู้ใช้ปรับเป้าหมายกลับขึ้นเองได้
- [x] วันที่ใบอนุญาตเป็นสีแดง มีคำเตือนชัดเจนก่อนเริ่ม

## หมายเหตุ — พฤติกรรมของสีแดงที่ยังไม่ได้เขียนไว้ที่ไหนอย่างเป็นทางการ

ตัดสินใจว่าสีแดงไม่บังคับหยุด แค่เตือนชัดเจนแล้วให้ผู้ใช้ตัดสินใจเอง (เหมือนสีเหลืองที่
"แนะนำ ไม่ใช่บังคับ" ตามตั๋วนี้เอง) แต่การตัดสินใจนี้ยังไม่เคยถูกเขียนไว้ที่ไหนอย่างเป็นทางการ
ในสเปกหรือตั๋วอื่น และตั๋วนี้เองก็ไม่มีปุ่ม "เริ่มวิ่ง" ให้บังคับด้วยอยู่แล้ว (ตั๋ว 11 เป็นเจ้าของหน้าวิ่งจริง)
จึงเท่ากับตั๋วนี้กำหนดพฤติกรรมของสีแดงล่วงหน้าให้ตั๋ว 11 โดยไม่ได้ตั้งใจ ทีมควรยืนยันก่อนตั๋ว 11
ว่าจะเอาแบบนี้จริงหรือจะให้สีแดงบล็อกปุ่มเริ่มวิ่งจริง ๆ

## ต้องยืนยันบนเครื่องจริง

- เลือกชนิดเป้าหมาย ค่าที่ตั้งไว้ให้ และปุ่ม +/- ทำงานลื่นไม่มีอาการหน่วง
- วันที่ทดสอบจริงเป็นสีเหลือง (ถ้ามี) เห็นการ์ดลดเป้าหมายกับปุ่มยืนยันกลับขึ้นจริง
