# 01: วางฐาน ธีมสว่างมืด ฟอนต์ไทย และโครงห้าแท็บ

**Blocked by:** None (can start immediately)

**Status:** done pending device check — commit 06e4f78

## What to build

แอปเปิดขึ้นมาเป็นภาษาไทยทั้งหมด มีแท็บล่างห้าแท็บคือ หน้าหลัก ที่วิ่ง วิ่ง ชุมชน และโปรไฟล์ กดสลับได้ครบทุกแท็บ และมีปุ่มสลับธีมสว่างกับมืดที่ทำงานได้จริงและจำค่าไว้เมื่อปิดเปิดแอปใหม่

ก่อนอื่นต้องล้างเนื้อหาตัวอย่างของ Expo starter ออกให้หมด ทั้งจอ explore จอ modal คอมโพเนนต์ hello-wave และ parallax-scroll-view รวมถึงรูปโลโก้ React ที่ไม่ได้ใช้ นี่คือการ prefactor ที่ต้องทำก่อนตั๋วอื่นทุกใบ เพราะถ้าปล่อยไว้จะมีคนไปฮาร์ดโค้ดสีทับระบบสีกลาง

สีทุกสีในแอปต้องมาจากตัวแปรกลางที่เดียว ห้ามเขียนรหัสสีลงในจอโดยตรง

## Acceptance criteria

- [x] ไม่เหลือไฟล์หรือรูปตัวอย่างของ Expo starter ในโปรเจกต์
- [ ] แท็บล่างห้าแท็บชื่อภาษาไทยครบ กดสลับได้ทุกแท็บโดยไม่ error
- [ ] สลับธีมสว่างกับมืดแล้วทุกจอเปลี่ยนสีตาม และค่าที่เลือกยังอยู่หลังปิดเปิดแอป
- [x] ค่าเริ่มต้นของธีมคือสว่าง
- [ ] ตัวอักษรไทยแสดงสระและวรรณยุกต์ถูกตำแหน่งทุกจอ
- [x] typecheck ผ่าน

## ต้องยืนยันบนเครื่องจริง

สามข้อที่ยังไม่ติ๊กต้องเปิดแอปบนมือถือถึงจะรู้ เครื่องมือบนเครื่องพัฒนายืนยันแทนไม่ได้
bundle ของ Android คอมไพล์ผ่านแล้ว typecheck และ lint สะอาด แต่นั่นไม่ได้แปลว่าตาเห็นแล้วถูก

- แท็บล่างห้าแท็บกดสลับได้ทุกแท็บโดยไม่ error
- สลับธีมแล้วทุกจอเปลี่ยนสีตาม และค่ายังอยู่หลังปิดเปิดแอป
- ตัวอักษรไทยแสดงสระและวรรณยุกต์ถูกตำแหน่งทุกจอ
