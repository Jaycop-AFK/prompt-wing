# 18: จอเข้าสู่ระบบและเพิ่มเติมแบบจำลอง

**Blocked by:** 01

**Status:** done

## What to build

ผู้ใช้เห็นหน้าเข้าสู่ระบบและสมัครสมาชิกตามแบบร่าง มีช่องอีเมลกับรหัสผ่าน และปุ่ม Google Apple Facebook ครบตามภาพ กดผ่านเข้าแอปได้

นี่เป็นระบบจำลอง เก็บแค่ชื่อผู้ใช้ในเครื่อง ห้ามเก็บรหัสผ่านแม้จะเป็นระบบจำลอง ปุ่มของผู้ให้บริการภายนอกยังไม่ได้ต่อ OAuth จริง ต้องมีป้ายกำกับให้ผู้ใช้และผู้ชมงานเห็นว่าส่วนนี้เป็นภาพจำลอง ดู ADR 0003

หน้าเพิ่มเติมมีการแจ้งเตือน หน่วยการวัด ภาษา ช่วยเหลือ เกี่ยวกับเรา และออกจากระบบ ตามแบบร่าง

## Acceptance criteria

- [x] กดผ่านหน้าเข้าสู่ระบบเข้าแอปได้
- [x] ไม่มีการเก็บรหัสผ่านลงเครื่องเลย
- [x] ปุ่มผู้ให้บริการภายนอกแสดงครบตามแบบและมีป้ายกำกับว่ายังไม่ได้ต่อจริง
- [x] หน้าเพิ่มเติมมีรายการครบตามแบบร่าง
- [x] ออกจากระบบแล้วกลับมาหน้าเข้าสู่ระบบได้

## หมายเหตุ (ปิดตั๋ว)

### ไม่มี "แบบร่าง" ให้เทียบจริง

ตั๋วอ้างถึงแบบร่างสามครั้งแต่ไม่มีไฟล์ภาพมอคอัพอยู่ในโปรเจกต์นี้เลย (ค้นทั้ง repo แล้ว) เป็นสถานการณ์
เดียวกับภาพในสไลด์ที่ตั๋ว 07 อ้างถึงตอนออกแบบตัวละคร คือมีอยู่จริงตอนวางแผนแต่เอเจนต์เขียนโค้ดไม่มี
สิทธิ์เข้าถึง จึงสร้างตามเนื้อหาที่ตั๋วเขียนไว้ตรง ๆ แทน (อีเมล+รหัสผ่าน+ปุ่ม Google/Apple/Facebook,
และรายการ 6 อย่างของหน้าเพิ่มเติม) ซึ่งตั๋วระบุไว้ครบอยู่แล้วในตัวข้อความเอง ไม่ต้องพึ่งภาพก็ได้เนื้อหา
ครบ แต่การจัดวาง/สัดส่วนหน้าจอจริงยังไม่เคยเทียบกับแบบร่างต้นฉบับเลย

### สถาปัตยกรรมที่เลือก

ใช้ `Stack.Protected` ของ expo-router 6 (ยืนยันจากเอกสารเวอร์ชัน v54 ตรง ๆ ตาม AGENTS.md ไม่ใช่ความรู้
เดิมเกี่ยวกับ React Navigation) กันเส้นทางทั้งหมดไว้หลัง `username !== null` ยกเว้นจอเข้าสู่ระบบ สลับกัน
เองอัตโนมัติเมื่อ `username` เปลี่ยนค่า ไม่ต้อง navigate มือตอนออกจากระบบ (ตรวจกับเอกสารทางการแล้วว่า
`signOut()` ของตัวอย่างจริงก็ไม่ navigate มือเหมือนกัน) หน้า splash ค้างไว้จนกว่าจะรู้สถานะเข้าสู่ระบบ
จริง ไม่ใช่แค่ฟอนต์โหลดเสร็จ กัน RootNavigator ไม่ให้ mount จอไหนเลยก่อนอ่านค่าที่บันทึกไว้เสร็จ ทำให้
ไม่มีทางกดปุ่มเข้าสู่ระบบ/ออกจากระบบระหว่างที่ยังโหลดค่าเดิมอยู่ได้เลย (ไม่ต้องมี editCount guard
แบบที่ตั๋วอื่นเคยต้องเพิ่ม เพราะสถาปัตยกรรมนี้ตัดโอกาสชนกันทิ้งไปตั้งแต่ต้น)

### เก็บทำความสะอาด

`components/ui/coming-soon.tsx` ไม่มีที่ใช้เหลือแล้วทั้ง repo หลังจากตั๋วนี้แทนที่ placeholder สุดท้าย
ในหน้าโปรไฟล์ (ที่เหลืออีกสองจุดในแท็บที่วิ่ง/ชุมชนถูกแทนที่ตอนทำตั๋ว 19 ต่อทันที) ลบไฟล์นี้ทิ้งแล้ว

### ดุลพินิจเล็กน้อยที่ตั้งใจไม่แก้

ช่องกรอกในหน้าเข้าสู่ระบบติดป้าย "อีเมล" แต่ภายในเก็บเป็น `username` ตรง ๆ โดยไม่ตรวจรูปแบบอีเมลเลย
เพราะเป็นระบบจำลองที่รับอะไรก็ได้ที่ไม่ว่างเปล่า ตรงตามเจตนาของ ADR 0003 ป้ายกำกับการเข้าถึงของปุ่ม
OAuth ก็ยังไม่พูดถึงคำว่า "จำลอง" ในตัวมันเอง (พึ่ง MockBadge ข้างเคียงแทน) ทั้งสองจุดเป็นรายละเอียด
เล็กน้อยที่ไม่กระทบ AC ข้อไหนเลย จึงปล่อยไว้ตามนี้
