# 12: วัด cadence จากเซ็นเซอร์ระหว่างวิ่ง

**Blocked by:** 11

**Status:** ready-for-agent

## What to build

ระหว่างวิ่ง แอปอ่าน accelerometer แล้วคำนวณ cadence เป็นก้าวต่อนาที แสดงสดบนหน้าวิ่ง

ต้องเก็บ cadence เป็นชุดตัวอย่างตลอด Session ไม่ใช่เก็บค่าเดียวตอนจบ เพราะ FormScore ต้องรู้ว่ามันตกตอนไหนของการวิ่ง

การอ่านเซ็นเซอร์ต้องไม่ทำให้แอปกระตุกหรือกินแบตจนผิดปกติ และต้องหยุดอ่านเมื่อผู้ใช้กดหยุดชั่วคราว

## Acceptance criteria

- [ ] cadence แสดงสดระหว่างวิ่งและใกล้เคียงกับการนับด้วยมือ
- [ ] cadence ถูกเก็บเป็นชุดตัวอย่างตลอดการวิ่ง ไม่ใช่ค่าเดียว
- [ ] หยุดอ่านเซ็นเซอร์เมื่อกดหยุดชั่วคราวและกลับมาอ่านต่อเมื่อวิ่งต่อ
- [ ] แอปไม่กระตุกขณะอ่านเซ็นเซอร์
- [ ] จัดการกรณีเครื่องไม่มีเซ็นเซอร์โดยไม่ทำให้แอปพัง
