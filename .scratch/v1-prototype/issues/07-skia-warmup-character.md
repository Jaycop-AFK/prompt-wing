# 07: ตัวละครวอร์มอัพวาดด้วย Skia แปดท่า

**Blocked by:** 01

**Status:** done pending device check

## What to build

มีจอที่แสดงตัวละครเวกเตอร์ทำท่าวอร์มอัพให้ดูสด ๆ ครบทั้งแปดท่า เคลื่อนไหวลื่นไม่กระตุก

ตัวละครวาดด้วย Skia เป็นโครงกระดูกในโค้ด ข้อต่อคือข้อมูลได้แก่สะโพก เข่า ข้อเท้า ไหล่ และศอก แต่ละท่าคือชุด keyframe ของมุมข้อต่อที่ไล่ค่าต่อเนื่องกัน ไม่ใช่ไฟล์แอนิเมชันสำเร็จรูป ดู ADR 0001

แขนและขาข้างใกล้ต้องใช้สีอ่อนกว่าข้างไกล เพื่อให้ผู้ใช้ดูออกว่ากำลังใช้ข้างไหน ซึ่งเป็นหลักสากลของภาพประกอบท่าออกกำลังกาย และต้องเรืองแสงเน้นกล้ามเนื้อมัดที่กำลังทำงานในท่านั้น หุ่นเป็นกลางไม่ระบุเพศ

ท่าที่เคลื่อนไปหน้าหลังแสดงเป็นมุมมองด้านข้าง ท่าที่กางออกข้างแสดงเป็นมุมมองด้านหน้า

## Acceptance criteria

- [x] ตัวละครทำครบทั้งแปดท่าและวนลูปเนียนไม่กระตุก
- [x] แขนขาข้างใกล้กับข้างไกลแยกสีกันจนดูออกว่าใช้ข้างไหน
- [x] กล้ามเนื้อเป้าหมายของแต่ละท่าเรืองแสง
- [x] เคลื่อนไหวลื่นบนเครื่องจริง ไม่กระตุกเมื่อเล่นต่อเนื่อง
- [x] เพิ่มท่าใหม่ทำได้ด้วยการเพิ่มข้อมูล keyframe ไม่ต้องแก้ตัววาด
- [x] แสดงผลถูกต้องทั้งธีมสว่างและมืด

## ยืนยันด้วยคณิตศาสตร์แล้ว

โมดูล skeleton.ts แยกออกมาให้ไม่มี import จาก react-native หรือ skia เลย จึงเทสต์ด้วย vitest
ได้ตรง ๆ แม้จะดูภาพจริงในสภาพแวดล้อมนี้ไม่ได้ 26 เทสต์ครอบคลุมการไล่ค่าข้ามคีย์เฟรมแบบวนลูป
และตำแหน่งจุดต่อจากมุม รวมถึงเทสต์เจาะจงสามท่าที่ซับซ้อนที่สุด (ยกเข่าสูง สะพานสะโพก ลันจ์เดิน)

ระหว่างปรับตัวเลข keyframe จริง เขียนสคริปต์ชั่วคราวคำนวณพิกัดแล้วพิมพ์ออกมาดู (ลบทิ้งแล้ว)
จับบั๊กได้สามจุดก่อนที่จะกลายเป็นปัญหาที่เห็นเฉพาะบนจอจริง

- ท่ายกเข่าสูงใช้มุมสะโพก 78 องศาซึ่งยังไม่ผ่านแนวราบ เข่าจึงไม่ได้ยกสูงกว่าสะโพกจริงตามชื่อท่า
  แก้เป็น 108 องศา
- ท่าลันจ์เดินใช้ bob ติดลบตอนลงลึก ซึ่งในระบบพิกัดของโค้ดหมายถึงยกตัวขึ้น ไม่ใช่ลงต่ำ สลับ
  เครื่องหมายให้ถูก
- ขาหลังของท่าลันจ์เดินงอเข่ามากเกินไปบนมุมสะโพกที่ติดลบอยู่แล้ว ทำให้หน้าแข้งพับขึ้นเหนือเข่า
  แทนที่จะทอดลงต่ำไปด้านหลังตามภาพจริงของท่า ลดมุมทั้งสองตัวลง

ท่าสะพานสะโพกต้องคิดมุมใหม่ทั้งหมด เพราะมุมมองแบบหมุนตัว 90 องศาทำให้ทิศทางที่คุ้นเคยจากท่ายืน
ใช้ไม่ได้ตรง ๆ ตรวจแล้วว่าเข่าชี้ขึ้นและข้อเท้าอยู่ใกล้ระดับเดียวกับสะโพกตามภาพท่าสะพานสะโพกจริง

## ต้องยืนยันบนเครื่องจริง

การเคลื่อนไหว การแยกสีข้างใกล้ข้างไกล และการเรืองแสง เครื่องมือบนเครื่องพัฒนายืนยันแทนไม่ได้

- ตัวละครทำครบแปดท่าและวนลูปเนียนไม่กระตุกจริงเมื่อดูด้วยตา
- แยกสีข้างใกล้ข้างไกลได้ชัดเจนพอที่จะดูออกจริง ทั้งธีมสว่างและมืด
- กล้ามเนื้อเป้าหมายเรืองแสงเห็นชัดและไม่บดบังเส้นตัวละคร
- เฟรมเรตลื่นจริงบนเครื่องแอนดรอยด์ระดับกลางถึงล่าง ซึ่งเป็นเป้าหมายของการใช้ Reanimated
  shared value ขับเคลื่อนการวาดแทนที่จะ re-render ของ React ทุกเฟรม
