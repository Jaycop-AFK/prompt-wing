# 07: ตัวละครวอร์มอัพวาดด้วย Skia แปดท่า

**Blocked by:** 01

**Status:** ready-for-agent

## What to build

มีจอที่แสดงตัวละครเวกเตอร์ทำท่าวอร์มอัพให้ดูสด ๆ ครบทั้งแปดท่า เคลื่อนไหวลื่นไม่กระตุก

ตัวละครวาดด้วย Skia เป็นโครงกระดูกในโค้ด ข้อต่อคือข้อมูลได้แก่สะโพก เข่า ข้อเท้า ไหล่ และศอก แต่ละท่าคือชุด keyframe ของมุมข้อต่อที่ไล่ค่าต่อเนื่องกัน ไม่ใช่ไฟล์แอนิเมชันสำเร็จรูป ดู ADR 0001

แขนและขาข้างใกล้ต้องใช้สีอ่อนกว่าข้างไกล เพื่อให้ผู้ใช้ดูออกว่ากำลังใช้ข้างไหน ซึ่งเป็นหลักสากลของภาพประกอบท่าออกกำลังกาย และต้องเรืองแสงเน้นกล้ามเนื้อมัดที่กำลังทำงานในท่านั้น หุ่นเป็นกลางไม่ระบุเพศ

ท่าที่เคลื่อนไปหน้าหลังแสดงเป็นมุมมองด้านข้าง ท่าที่กางออกข้างแสดงเป็นมุมมองด้านหน้า

## Acceptance criteria

- [ ] ตัวละครทำครบทั้งแปดท่าและวนลูปเนียนไม่กระตุก
- [ ] แขนขาข้างใกล้กับข้างไกลแยกสีกันจนดูออกว่าใช้ข้างไหน
- [ ] กล้ามเนื้อเป้าหมายของแต่ละท่าเรืองแสง
- [ ] เคลื่อนไหวลื่นบนเครื่องจริง ไม่กระตุกเมื่อเล่นต่อเนื่อง
- [ ] เพิ่มท่าใหม่ทำได้ด้วยการเพิ่มข้อมูล keyframe ไม่ต้องแก้ตัววาด
- [ ] แสดงผลถูกต้องทั้งธีมสว่างและมืด
