# 08: หน้าวอร์มอัพและตัวเล่นนับถอยหลัง

**Blocked by:** 05, 07

**Status:** done pending device check

## What to build

ผู้ใช้กดวอร์มอัพจากหน้าแรก เลือกได้ว่าจะใช้เวลาห้าสิบหรือสิบห้านาที แล้วได้ WarmUpSet ที่ระบบเลือกมาให้สำหรับวันนี้โดยเฉพาะ เห็นรายการท่าพร้อมเวลาของแต่ละท่าก่อนเริ่ม

พอกดเริ่ม ตัวละครทำท่าให้ดูพร้อมนาฬิกานับถอยหลังของท่านั้น เครื่องสั่นเตือนตอนเปลี่ยนท่า ผู้ใช้ข้ามท่าที่ทำไม่ได้ หยุดชั่วคราว และออกกลางคันได้

ต้องมีข้อความบอกผู้ใช้ว่าทำไมชุดนี้ถึงถูกเลือกมา เช่นบอกว่าวันนี้ร้อนจึงตัดท่ากระโดดออก หรือครั้งก่อน cadence ตกจึงเพิ่มท่าน่อง ไม่งั้นผู้ใช้จะไม่รู้ว่าระบบปรับให้จริง

## Acceptance criteria

- [x] เลือกความยาวได้สามแบบและได้ชุดท่าที่ต่างกันจริง
- [ ] ชุดท่าเปลี่ยนตามใบอนุญาตวิ่งวันนี้และตาม FormScore ครั้งก่อน
- [x] ตัวเล่นนับถอยหลังของแต่ละท่าเดินถูกต้องและไปท่าถัดไปเองเมื่อหมดเวลา
- [ ] เครื่องสั่นเตือนตอนเปลี่ยนท่า
- [x] ข้ามท่า หยุดชั่วคราว และออกกลางคันได้
- [x] แสดงเหตุผลว่าทำไมชุดนี้ถูกเลือกมา

## หมายเหตุ — สอง AC ที่ยังไม่สมบูรณ์ตามตัวอักษร

**"ชุดท่าเปลี่ยนตามใบอนุญาตวิ่งวันนี้และตาม FormScore ครั้งก่อน"** — ครึ่งแรกทำงานจริง
(clearanceFactors มาจาก useTodayConditions ของตั๋ว 03 สด ๆ) ครึ่งหลังยังไม่มีทางทำได้จริง
เพราะยังไม่มีที่เก็บ Session/FormScore ในเครื่อง (ตั๋ว 13 ยังไม่ได้ทำ) จึงส่ง
cadenceDroppedLastTime เป็น false ตายตัวไปก่อน โค้ดเขียนคอมเมนต์บอกไว้ตรง ๆ ไม่ได้แอบทำ
ตอนตั๋ว 13 เสร็จ ต้องกลับมาต่อสายจุดนี้

**"เครื่องสั่นเตือนตอนเปลี่ยนท่า"** — ทำแล้วและใช้ expo-haptics ซึ่งอยู่ใน Expo Go ตรวจสอบ
API แล้วว่าตรงกับเวอร์ชันที่ติดตั้ง แต่ยังไม่เคยรู้สึกจริงบนเครื่อง ต้องยืนยันด้วยมือ

หน้า warmup-preview.tsx ของตั๋ว 07 ถูกลบแล้ว เพราะหน้าจริงนี้ทำหน้าที่แสดงตัวละครครบทุกท่า
ได้อยู่แล้วในขั้นตอนก่อนเริ่ม (setup stage)

## ต้องยืนยันบนเครื่องจริง

- นับถอยหลังลื่น ไม่กระตุก และเปลี่ยนท่าเองเมื่อหมดเวลาจริง
- เครื่องสั่นตอนเปลี่ยนท่าจริง ทั้งตอนหมดเวลาอัตโนมัติและตอนกดข้าม
- หยุดชั่วคราวแล้วกดเล่นต่อได้โดยเวลาไม่กระโดด
- กดออกกลางคันแล้วมี dialog ยืนยันจริง ไม่ออกทันทีโดยไม่ถาม
