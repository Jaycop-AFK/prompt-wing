# 08: หน้าวอร์มอัพและตัวเล่นนับถอยหลัง

**Blocked by:** 05, 07

**Status:** ready-for-agent

## What to build

ผู้ใช้กดวอร์มอัพจากหน้าแรก เลือกได้ว่าจะใช้เวลาห้าสิบหรือสิบห้านาที แล้วได้ WarmUpSet ที่ระบบเลือกมาให้สำหรับวันนี้โดยเฉพาะ เห็นรายการท่าพร้อมเวลาของแต่ละท่าก่อนเริ่ม

พอกดเริ่ม ตัวละครทำท่าให้ดูพร้อมนาฬิกานับถอยหลังของท่านั้น เครื่องสั่นเตือนตอนเปลี่ยนท่า ผู้ใช้ข้ามท่าที่ทำไม่ได้ หยุดชั่วคราว และออกกลางคันได้

ต้องมีข้อความบอกผู้ใช้ว่าทำไมชุดนี้ถึงถูกเลือกมา เช่นบอกว่าวันนี้ร้อนจึงตัดท่ากระโดดออก หรือครั้งก่อน cadence ตกจึงเพิ่มท่าน่อง ไม่งั้นผู้ใช้จะไม่รู้ว่าระบบปรับให้จริง

## Acceptance criteria

- [ ] เลือกความยาวได้สามแบบและได้ชุดท่าที่ต่างกันจริง
- [ ] ชุดท่าเปลี่ยนตามใบอนุญาตวิ่งวันนี้และตาม FormScore ครั้งก่อน
- [ ] ตัวเล่นนับถอยหลังของแต่ละท่าเดินถูกต้องและไปท่าถัดไปเองเมื่อหมดเวลา
- [ ] เครื่องสั่นเตือนตอนเปลี่ยนท่า
- [ ] ข้ามท่า หยุดชั่วคราว และออกกลางคันได้
- [ ] แสดงเหตุผลว่าทำไมชุดนี้ถูกเลือกมา
