# 05: ตรรกะเลือกชุดวอร์มอัพตามหลัก RAMP

**Blocked by:** 02

**Status:** ready-for-agent

## What to build

เพิ่มฟังก์ชันในโมดูลตัวตัดสินใจที่รับ RunClearance ของวันนี้ FormScore ครั้งก่อน SessionTarget และจำนวนนาทีที่ผู้ใช้มี แล้วคืน WarmUpSet

ชุดท่ามาตรฐานมีแปดท่า วิ่งเหยาะอยู่กับที่อยู่ในขั้น Raise สะพานสะโพก เขย่งปลายเท้า และกระดกปลายเท้าอยู่ในขั้น Activate แกว่งขา ลันจ์เดิน และหมุนข้อเท้าอยู่ในขั้น Mobilise ยกเข่าสูงอยู่ในขั้น Potentiate ส่วนวงแขนเป็นท่าสำรองสำหรับชุดที่ยาวขึ้นตอนอากาศเย็น

ทุกชุดที่คืนออกมาต้องมีท่าครบทั้งสี่ขั้นเสมอ ไม่ว่าผู้ใช้จะเลือกห้าสิบหรือสิบห้านาที การย่อชุดให้สั้นลงทำโดยลดจำนวนท่าในขั้น Mobilise และลดเวลาต่อท่า ห้ามตัดขั้นทิ้ง

วันที่ร้อนต้องไม่มีท่ากระโดด วันที่ FormScore ครั้งก่อนบอกว่า cadence ตกช่วงท้ายต้องมีท่าน่องและท่าหน้าแข้ง SessionTarget ที่เป็นระยะไกลต้องได้ชุดที่ยาวขึ้น

## Acceptance criteria

- [ ] ทุกชุดที่คืนออกมามีท่าครบทั้งสี่ขั้น RAMP ไม่ว่าจะเลือกกี่นาที มีเทสต์ยืนยันทั้งสามความยาว
- [ ] ผลรวมเวลาของชุดไม่เกินเวลาที่ผู้ใช้มี มีเทสต์ยืนยัน
- [ ] วันที่ร้อนไม่มีท่ากระโดดในชุด มีเทสต์ยืนยัน
- [ ] FormScore ที่บอกว่า cadence ตกทำให้ชุดมีท่าน่องและหน้าแข้ง มีเทสต์ยืนยัน
- [ ] SessionTarget ระยะไกลได้ชุดที่ยาวกว่าระยะสั้น มีเทสต์ยืนยัน
