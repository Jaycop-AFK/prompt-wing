# 05: ตรรกะเลือกชุดวอร์มอัพตามหลัก RAMP

**Blocked by:** 02

**Status:** done

## What to build

เพิ่มฟังก์ชันในโมดูลตัวตัดสินใจที่รับ RunClearance ของวันนี้ FormScore ครั้งก่อน SessionTarget และจำนวนนาทีที่ผู้ใช้มี แล้วคืน WarmUpSet

ชุดท่ามาตรฐานมีแปดท่า วิ่งเหยาะอยู่กับที่อยู่ในขั้น Raise สะพานสะโพก เขย่งปลายเท้า และกระดกปลายเท้าอยู่ในขั้น Activate แกว่งขา ลันจ์เดิน และหมุนข้อเท้าอยู่ในขั้น Mobilise ยกเข่าสูงอยู่ในขั้น Potentiate ส่วนวงแขนเป็นท่าสำรองสำหรับชุดที่ยาวขึ้นตอนอากาศเย็น

ทุกชุดที่คืนออกมาต้องมีท่าครบทั้งสี่ขั้นเสมอ ไม่ว่าผู้ใช้จะเลือกห้าสิบหรือสิบห้านาที การย่อชุดให้สั้นลงทำโดยลดจำนวนท่าในขั้น Mobilise และลดเวลาต่อท่า ห้ามตัดขั้นทิ้ง

วันที่ร้อนต้องไม่มีท่ากระโดด วันที่ FormScore ครั้งก่อนบอกว่า cadence ตกช่วงท้ายต้องมีท่าน่องและท่าหน้าแข้ง SessionTarget ที่เป็นระยะไกลต้องได้ชุดที่ยาวขึ้น

## Acceptance criteria

- [x] ทุกชุดที่คืนออกมามีท่าครบทั้งสี่ขั้น RAMP ไม่ว่าจะเลือกกี่นาที มีเทสต์ยืนยันทั้งสามความยาว
- [x] ผลรวมเวลาของชุดไม่เกินเวลาที่ผู้ใช้มี มีเทสต์ยืนยัน
- [x] วันที่ร้อนไม่มีท่ากระโดดในชุด มีเทสต์ยืนยัน
- [x] FormScore ที่บอกว่า cadence ตกทำให้ชุดมีท่าน่องและหน้าแข้ง มีเทสต์ยืนยัน
- [x] SessionTarget ระยะไกลได้ชุดที่ยาวกว่าระยะสั้น มีเทสต์ยืนยัน

## หมายเหตุสำคัญ — ข้อขัดแย้งระหว่างสอง acceptance criteria

"ทุกชุดต้องมีท่าครบทั้งสี่ขั้น RAMP เสมอ" กับ "วันที่ร้อนต้องไม่มีท่ากระโดด" ขัดกันเองในทางปฏิบัติ
เพราะท่าเดียวในขั้น Potentiate ของแปดท่าคือท่ายกเข่าสูง ซึ่งเป็นท่ากระโดดท่าเดียวในทั้งชุด
ถ้าตัดออกจริงตามตัวอักษร ขั้น Potentiate จะไม่มีท่าเหลือเลยในวันที่ร้อน ขัดกับข้อแรก

ตัดสินใจเลือกรักษาความครบของ RAMP ไว้ก่อน โดยวันที่ร้อนจะ "ลดเวลาท่ายกเข่าสูงลงเหลือ 40%"
แทนการนำออกทั้งหมด เหตุผลคือการไม่มีขั้น Potentiate เลยดูเป็นผลเสียที่ใหญ่กว่าการทำท่ากระโดด
สั้น ๆ ไม่กี่วินาที นี่คือการตัดสินใจของผู้ช่วยเขียนโค้ด ไม่ใช่ทีม ถ้าต้องการให้ตัดออกทั้งหมดจริง ๆ
ต้องเพิ่มท่า Potentiate สำรองที่ไม่ใช่ท่ากระโดดเข้ามาก่อน (ตอนนี้ยังไม่มี)

catalogMoveIds() ใน warmup-set.ts กับ MOVES ใน components/warmup/moves.ts เป็นรายชื่อ
ที่ดูแลแยกกันด้วยมือ มีเทสต์ cross-check ใน warmup-set.test.ts คอยจับความไม่ตรงกันแล้ว
