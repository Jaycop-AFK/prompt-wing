# 09: โปรไฟล์ BMI และเป้าหมายระยะยาวที่มีผลจริง

**Blocked by:** 01, 04

**Status:** done

## What to build

ผู้ใช้กรอกน้ำหนัก ส่วนสูง อายุ และเพศในหน้าโปรไฟล์ แล้วเห็น BMI พร้อมแถบบอกว่าตัวเองอยู่ช่วงไหน โดยไม่ต้องไปหาข้อมูลเอง

ผู้ใช้เลือก Objective ได้ระหว่างลดน้ำหนัก สุขภาพ มาราธอน และเพิ่มความอึด และเมื่อเปลี่ยน แถบ DailyGoal บนหน้าแรกต้องขยับทันทีต่อหน้าต่อตา ข้อนี้สำคัญเพราะถ้ากดแล้วไม่มีอะไรเปลี่ยน มันคือปุ่มตาย

ข้อมูลทั้งหมดเก็บในเครื่อง

## Acceptance criteria

- [x] กรอกน้ำหนักส่วนสูงอายุเพศได้และค่ายังอยู่หลังปิดเปิดแอป
- [x] BMI คำนวณถูกต้องและมีแถบบอกช่วง (ใช้เกณฑ์กรมอนามัย ไม่ใช่เกณฑ์สากล ดูหมายเหตุ)
- [x] เปลี่ยน Objective แล้ว DailyGoal บนหน้าแรกเปลี่ยนทันที (context ตัวเดียวกัน ทั้งสี่แบบให้ตัวเลขต่างกันจริง 4.00 / 3.00 / 5.00 / 3.50)
- [x] แถบความคืบหน้า DailyGoal แสดงบนหน้าแรก

## หมายเหตุ (ปิดตั๋ว)

### เกณฑ์ BMI: เคยใช้ผิด แก้แล้ว

รอบแรกใช้ "action points" 23/27.5 จากรายงานองค์การอนามัยโลกปี 2004 โดยเข้าใจว่าเป็นเกณฑ์ที่ไทยใช้
รีวิวแกนมาตรฐานทักว่าน่าจะผิด ตรวจสอบกับข้อมูลกรมอนามัยแล้วพบว่าทักถูก เกณฑ์ที่ใช้จริงในไทยคือ
ต่ำกว่า 18.5 ผอม, 18.5-22.9 ปกติ, 23-24.9 น้ำหนักเกิน, 25-29.9 อ้วนระดับ 1, ตั้งแต่ 30 อ้วนระดับ 2
ถ้าใช้ 27.5 เป็นจุดเริ่มของอ้วนตามที่ทำไปตอนแรก คนที่ BMI 26 จะถูกบอกว่าแค่ "น้ำหนักเกิน" ทั้งที่
เกณฑ์ไทยจัดว่าอ้วนระดับ 1 แล้ว คือเตือนน้อยกว่าที่ควรในแอปด้านสุขภาพ แก้เป็นเกณฑ์กรมอนามัยเต็มชุด
ห้าระดับแล้ว พร้อมเทสต์ที่ตรึงไว้ว่า BMI 26 ต้องได้ obese1 เพื่อกันไม่ให้ย้อนกลับไปใช้เกณฑ์ชุดเดิม

### เกินขอบเขตของตั๋วที่ทำเพิ่ม

เชื่อมน้ำหนักจริงเข้ากับการคำนวณแคลอรี (`estimateSessionSummary` และ `caloriesFromDistance`) ด้วย
ไม่ได้อยู่ใน AC ทั้งสี่ข้อ แต่ user story 50 ในสเปกระบุว่าน้ำหนักมีไว้ให้ "คำนวณ BMI และแคลอรี"
และถ้าไม่ทำ ช่องน้ำหนักจะกลายเป็นช่องที่กรอกแล้วไม่มีผลกับแคลอรีเลย ซึ่งเป็นปัญหาเดียวกับ "ปุ่มตาย"
ที่ตั๋วนี้เตือนไว้เอง ผู้ใช้ที่ไม่กรอกน้ำหนักยังได้ตัวเลขเดิมเป๊ะ (60 แคลอรี/กม.) ไม่มีอะไรพัง

### บั๊กจริงที่เจอและแก้ระหว่างรีวิว

- **แถบความคืบหน้าถอยหลังหลังวิ่งจบ** `computeDailyGoal` เดิมนับการวิ่งของวันนี้เข้าไปในประวัติที่ใช้
  คำนวณเป้าหมายของวันนี้เอง ทำให้ตัวหารขยับตามตัวเศษ เป้าหมายเพิ่มความอึดพลิกจาก 3.5 เป็น 6 กม.
  กลางวันทันทีที่วิ่งจบ คนที่เพิ่งวิ่งครบเป้าหมายจึงกลับเห็นว่าตัวเองยังไม่ถึงเป้า ตรงข้ามกับเหตุผล
  ที่มีแถบนี้ แก้ให้ตัดการวิ่งของวันนี้ออกจากประวัติที่ใช้คำนวณเสมอ พร้อมเทสต์สามตัว
- **ค่าที่จอรับแต่ที่เก็บไม่รับ หายเงียบตอนเปิดแอปใหม่** กรอกน้ำหนัก 500 ได้ แสดงผลได้ คำนวณ BMI ให้
  ด้วย แล้วหายไปตอนเปิดใหม่ แก้โดยทำ `PROFILE_FIELD_RANGE` ใน core/coach เป็นแหล่งความจริงเดียว
  ที่ทั้งจอและที่เก็บใช้ร่วมกัน พร้อมข้อความบอกช่วงที่ยอมรับให้ผู้ใช้เห็น
- **ผลข้างเคียงอยู่ในฟังก์ชันที่ส่งให้ setState** เขียนลงเครื่องอยู่ข้างใน updater ซึ่ง React เรียกซ้ำได้
  หลายครั้ง ย้ายไปอยู่ใน useEffect หลังหน้าจออัปเดตแล้ว ตามแบบเดียวกับ use-theme.tsx
- **ช่องที่ผู้ใช้แก้ระหว่างรออ่านค่าจากเครื่องอาจถูกทับ** ปิดช่องโหว่ด้วยตัวนับการแก้ของผู้ใช้
- **จอไม่ได้ใช้ธง loading ที่ hook เตรียมไว้** ทำให้เห็นค่าเริ่มต้นแวบหนึ่งแล้วกระโดดเป็นค่าจริง แก้แล้ว
- **ป้ายตัวเลขใต้แถบ BMI ไม่ตรงกับขอบสี** ป้ายกระจายเท่า ๆ กันแต่ขอบช่วงจริงไม่ได้อยู่ตรงนั้น
  คลาดกันได้ถึง 25% ของความกว้าง แก้ให้ป้ายกับแท่งใช้สัดส่วนชุดเดียวกันที่คำนวณจาก BMI_BANDS
- **เตือน "ค่านอกช่วง" ตั้งแต่พิมพ์ตัวเลขตัวแรก** พิมพ์ "175" จะผ่าน "1" กับ "17" ซึ่งต่ำกว่าขั้นต่ำ
  ทั้งคู่ ทุกช่องเลยขึ้นกรอบแดงตั้งแต่ตัวแรกเสมอ แก้ให้เตือนเฉพาะตอนค่าเกินขั้นสูงหรือออกจากช่องแล้ว

### สิ่งที่บอกผู้ใช้ตรง ๆ บนจอ

อายุกับเพศเก็บไว้แล้วแต่ยังไม่ถูกนำไปคำนวณอะไรในเวอร์ชันนี้ (BMI ใช้แค่น้ำหนักกับส่วนสูง แคลอรีใช้แค่
น้ำหนัก) เขียนบอกไว้บนจอแล้ว ไม่ปล่อยให้ผู้ใช้เข้าใจว่ากรอกไปแล้วมีผล คำแนะนำตามช่วง BMI กำกับไว้ว่า
เป็นแนวทางการวิ่งทั่วไป ไม่ใช่คำวินิจฉัยทางการแพทย์ และเป้าหมายสุขภาพกำกับไว้ว่าตามหลักการควรเป็น
สามวันต่อสัปดาห์ แต่แอปยังคิดเป็นรายวันทุกวัน วันพักจึงขึ้นว่ายังไม่ครบเสมอ (ข้อจำกัดที่ยกมาจากตั๋ว 04)

คำบรรยายของแต่ละเป้าหมายระยะยาวเขียนตามสิ่งที่โค้ดทำจริงเท่านั้น เช่นเพิ่มความอึดสลับตาม "ครั้งที่วิ่ง"
ไม่ใช่ "วัน" จึงไม่เขียนว่าสลับวันเว้นวัน และมาราธอนมักได้ตัวเลขน้อยกว่าระยะที่วิ่งมาจริง จึงไม่เขียนว่า
"เพิ่มระยะ" ทั้งจอยังไม่เคยรันบนเครื่องจริง ตรวจด้วย typecheck + เทสต์ (220 ผ่าน) + lint + bundle เท่านั้น
