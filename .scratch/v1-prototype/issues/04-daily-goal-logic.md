# 04: ตรรกะเป้าหมายรายวันจากเป้าหมายระยะยาว

**Blocked by:** 02

**Status:** done

## What to build

เพิ่มฟังก์ชันในโมดูลตัวตัดสินใจที่รับ Objective ของผู้ใช้กับประวัติ Session ย้อนหลัง แล้วคืน DailyGoal

ลดน้ำหนักให้เน้นเวลาและแคลอรีโดยระยะคงที่ สุขภาพให้สามวันต่อสัปดาห์ระยะสั้นคงที่ มาราธอนให้ระยะเพิ่มขึ้นทุกสัปดาห์แต่ห้ามเกินสิบเปอร์เซ็นต์ต่อสัปดาห์ตามหลักป้องกันบาดเจ็บ เพิ่มความอึดให้สลับวันหนักกับวันเบา

ผู้ใช้ที่ยังไม่มีประวัติเลยต้องได้ค่าเริ่มต้นที่ปลอดภัย ไม่ใช่ศูนย์และไม่ใช่ค่าที่สูงเกินจริง

## Acceptance criteria

- [x] Objective แต่ละแบบให้ผลลัพธ์ต่างกันจริง มีเทสต์ยืนยันทุกแบบ
- [x] มาราธอนไม่เพิ่มระยะเกินสิบเปอร์เซ็นต์ต่อสัปดาห์ มีเทสต์ยืนยัน
- [x] ผู้ใช้ที่ไม่มีประวัติได้ค่าเริ่มต้นที่ปลอดภัย มีเทสต์ยืนยัน
- [x] โมดูลยังคงไม่มี import จาก react-native หรือ expo

## หมายเหตุ

DailyGoal เป็นตัวเลขระยะทางของวันนี้วันเดียวตามนิยามใน CONTEXT.md ไม่มีที่เก็บความถี่
รายสัปดาห์ เป้าหมายสุขภาพที่ตั๋วนี้อยากได้ "สามวันต่อสัปดาห์" จึงยังทำไม่ได้ตามตัวอักษร
คืนระยะทางคงที่ทุกวันแทนไปก่อน คอมเมนต์ไว้ในโค้ดแล้วว่าต้องรอแนวคิดตารางซ้อมรายสัปดาห์
ซึ่งยังไม่มีในสเปกปัจจุบัน
