# Illustration sources

The three SVG files in this folder are individual [Open Doodles](https://www.opendoodles.com/) illustrations recolored to Prompt Wing green.

- `runner-sprinting.svg`: Sprinting
- `runner-strolling.svg`: Strolling
- `runner-selfie.svg`: Selfie

Each file also has a `-dark.svg` variant with light linework so the illustration remains legible on the dark theme. The pink Open Doodles accent was changed to Prompt Wing green in both variants.

Downloaded from the official Open Doodles asset host on 2026-09-02. Open Doodles dedicates the illustrations to the public domain under [CC0](https://www.opendoodles.com/about), permitting copying, modification, redistribution, and commercial use without attribution.
