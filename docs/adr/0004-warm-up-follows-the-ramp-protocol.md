# ชุดวอร์มอัพยึดตามหลัก RAMP

ท่าวอร์มอัพทุกท่าในแอปถูกกำกับว่าอยู่ในขั้นไหนของ RAMP (Raise, Activate, Mobilise, Potentiate) ตามกรอบของ Dr. Ian Jeffreys และการเลือก `WarmUpSet` แต่ละครั้งต้องหยิบท่าให้ครบทั้งสี่ขั้นเสมอ ไม่ใช่หยิบตามลำดับในรายการ

## เหตุผล

ห้าท่าในแบบร่างแรก (Leg Swing, High Knee, Walking Lunge, Arm Circle, Ankle Roll) เมื่อเทียบกับ RAMP แล้วอยู่ในขั้น Mobilise แทบทั้งหมด ขาดขั้น Raise, Activate และ Potentiate ไปทั้งสามขั้น

ขั้นที่ขาดหายไปสำคัญกับโปรเจกต์นี้เป็นพิเศษ เพราะขั้น **Activate** คือขั้นที่มีท่าน่อง (Calf Raise) และท่าหน้าแข้ง (Toe Raise) อยู่ ซึ่งตรงกับปัญหา "บาดเจ็บที่น่อง" ที่โปรเจกต์ตั้งไว้ตั้งแต่ต้น การไม่มีขั้นนี้แปลว่าแอปตั้งปัญหาไว้แล้วไม่ได้แก้

## ผลที่ตามมา

ชุดท่ามาตรฐานมีแปดท่า: วิ่งเหยาะอยู่กับที่ (R) · สะพานสะโพก, เขย่งปลายเท้า, กระดกปลายเท้า (A) · แกว่งขา, ลันจ์เดิน, หมุนข้อเท้า (M) · ยกเข่าสูง (P) ส่วน Arm Circle จากแบบร่างเดิมเก็บไว้เป็นท่าสำรองสำหรับชุดที่ยาวขึ้นตอนอากาศเย็น

เวลาเพิ่มท่าใหม่ในอนาคต ต้องระบุขั้น RAMP ของมันเสมอ ไม่งั้นตัวเลือกชุดวอร์มอัพจะหยิบมันไปใช้ผิดที่
