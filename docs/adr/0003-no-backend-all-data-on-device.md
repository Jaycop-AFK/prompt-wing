# ไม่มี backend ข้อมูลทั้งหมดอยู่ในเครื่อง

**ถูกยกเลิกแล้วโดย [ADR 0005](0005-migrate-to-supabase-backend.md)** เก็บไว้เป็นบันทึกเหตุผลของ
การตัดสินใจเดิมตอนวางแผน 14 วันแรก ไม่ใช่สถานะปัจจุบันของโค้ดอีกต่อไป อ่าน ADR 0005 สำหรับเหตุผล
ที่กลับคำตัดสินใจนี้และสถานะปัจจุบันจริง

พร้อมวิ่ง ไม่มีเซิร์ฟเวอร์และไม่มีฐานข้อมูลบนคลาวด์ ข้อมูลผู้ใช้ ประวัติการวิ่ง และที่วิ่งที่บันทึกไว้ เก็บด้วย `expo-sqlite` และ `AsyncStorage` ในเครื่องทั้งหมด หน้าเข้าสู่ระบบเป็นหน้าจอจำลองที่ไม่ยืนยันตัวตนจริง

## เหตุผล

เดิมตั้งใจใช้ Supabase แต่พอตัดสินใจว่าการเข้าสู่ระบบเป็นข้อมูลจำลอง การหาเพื่อนวิ่งเป็นข้อมูลจำลอง และประวัติการวิ่งเก็บในเครื่อง ก็ไม่เหลืองานให้ backend ทำเลยสักอย่าง การตั้งค่า Supabase จะใช้เวลาราวหนึ่งวันจากทั้งหมดสิบสี่วัน เพื่อฐานข้อมูลที่ว่างเปล่า

ผลพลอยได้ที่สำคัญกว่านั้นคือ **แอปทำงานได้ครบทุกอย่างโดยไม่ต้องมีอินเทอร์เน็ต** ยกเว้นการดึงข้อมูลอากาศและแผนที่ ถ้าเน็ตในห้องนำเสนอล่ม แอปยังวิ่ง ยังบันทึก และยังแสดงประวัติได้ ซึ่งเป็นความเสี่ยงที่เกิดขึ้นจริงบ่อยและทำให้งานทั้งสองสัปดาห์จบได้ในวินาทีเดียว

## ข้อควรระวัง

ห้ามเก็บรหัสผ่านลงเครื่องแม้จะเป็นระบบจำลอง เก็บแค่ชื่อผู้ใช้ และให้ช่องรหัสผ่านกรอกอะไรก็ผ่าน ปุ่ม Google, Apple และ Facebook มีไว้ให้ตรงกับแบบร่างเท่านั้น ยังไม่ได้ต่อ OAuth จริง
