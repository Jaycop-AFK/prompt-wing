# แพ็กเกจ Plus แบบจำลองเก็บใน user_metadata ของบัญชี Supabase

แพ็กเกจสมาชิก (Free / Plus รายเดือน / Plus รายปี) และการตั้งค่าแผนซ้อม เก็บเป็นคีย์ `subscription` และ `training_plan` ใน `user_metadata` ของบัญชี Supabase Auth เขียนผ่าน `supabase.auth.updateUser({ data })` (`storage/account-metadata.ts`) ไม่ได้สร้างตารางใหม่ในฐานข้อมูล การสมัคร เปลี่ยนรอบบิล และยกเลิก เป็นแค่การเปลี่ยนสถานะ ไม่มีการตัดเงิน

## เหตุผล

ผู้ใช้ (ทีมงาน) ขอให้กดสมัครและเปลี่ยนแพ็กเกจได้จริงระดับบัญชี แต่เป็น mock ที่เปลี่ยนสถานะเฉย ๆ เพื่อทดลองเปิดปิดฟีเจอร์ Plus ตอนนำเสนอ

- **ตามบัญชีไปทุกเครื่อง** ล็อกอินบัญชีเดียวกันบนมือถืออีกเครื่องก็เห็นแพ็กเกจเดิม ต่างจากการเก็บใน AsyncStorage ที่ผูกกับเครื่อง
- **ไม่ต้องรัน migration** ตอนทำฟีเจอร์นี้ไม่มี Supabase CLI หรือสิทธิ์จัดการฐานข้อมูลบนเครื่อง ถ้าโค้ดพึ่งตารางที่ยังไม่มี ฟีเจอร์จะพังจนกว่าจะมีคนไปรัน SQL เอง
- **ทุกจอเห็นพร้อมกันทันที** `updateUser` ยิง `USER_UPDATED` ให้ `onAuthStateChange` ก่อนคืนค่า `AuthProvider` จึงกระจาย `accountMetadata` ใหม่ให้ `useSubscription` และ `useTrainingPlan` ทุกจอโดยไม่ต้องมี Provider เพิ่ม
- Supabase รวมคีย์ที่ส่งไปเข้ากับของเดิมระดับบนสุด การบันทึกแพ็กเกจจึงไม่ลบแผนซ้อม และส่ง `null` เพื่อลบคีย์ได้

ระดับของแผนซ้อมไม่ได้เก็บไว้ คำนวณใหม่จากวันเริ่มแผนกับประวัติการวิ่งทุกครั้ง (`core/coach/training-plan.ts`) ส่วนการเปิดการเตือนซ้อมเก็บต่อเครื่องใน AsyncStorage เพราะการแจ้งเตือนถูกตั้งเวลาไว้ในเครื่อง

## ข้อจำกัดที่ยอมรับ และสิ่งที่ต้องเปลี่ยนก่อนเก็บเงินจริง

`user_metadata` ผู้ใช้แก้เองได้ผ่าน API สาธารณะ ใครรู้วิธีก็ตั้งตัวเองเป็น Plus ได้ ยอมรับได้เพราะเป็นโหมดทดลองที่ไม่มีเงินเกี่ยวข้อง และทุกจุดที่มีปุ่มสมัครบอกผู้ใช้ว่าไม่มีการตัดเงินจริง ข้อมูลที่อ่านไม่ออกถือเป็นแพ็กเกจฟรีเสมอ (`services/subscription.ts`)

ก่อนเก็บเงินจริงต้อง:

- ย้ายสิทธิ์สมาชิกไปที่ที่ผู้ใช้เขียนเองไม่ได้ เช่นตาราง `subscriptions` ที่ RLS ให้แค่อ่าน หรือ `app_metadata` แล้วให้ webhook ของร้านแอป (หรือ RevenueCat) เป็นคนเขียนหลังตรวจใบเสร็จ
- ทำการซื้อผ่าน App Store / Google Play ซึ่งต้องออกจาก Expo Go ไปใช้ development build (ดู [ADR 0002](0002-stay-in-expo-go-for-the-whole-project.md))
- เปลี่ยนการยกเลิกให้ใช้ได้จนจบรอบบิลที่จ่ายแล้ว และคิดส่วนต่างตอนสลับรายเดือนกับรายปีตามกติกาของร้านแอป ต้นแบบนี้เปลี่ยนทันทีเพื่อสาธิตเท่านั้น

`hooks/use-subscription.ts` เป็นจุดเดียวที่จอถามว่า `isPlus` ตอนย้ายที่เก็บจึงแก้แค่ hook กับ storage ไม่ต้องแก้จอ
